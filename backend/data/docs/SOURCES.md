## 이용 조건

- 정부·공공기관 공표 자료로, 출처 표시 후 프로토타입 내 인용에 사용한다. 답변에는 항상 문서명·기관을 출처 배지로 표기한다.
- 스냅숏 성격이므로 최신 규정과 다를 수 있음 — 데모 화면에 "수집일 기준" 문구를 함께 표시한다.
