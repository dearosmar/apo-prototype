# 「바다 건너 사장님」 프로토타입 실행계획 — 8/3 접수까지

**전제**: 1인 개발 + Claude 페어 프로그래밍 · 오늘(7/26)부터 8일 · 웹 메인 데모 + iOS 동행 앱(스캔·환율 위젯)

## 3원칙

1. **매일 저녁 '동작하는 버전'** — 완벽한 반쪽보다 거친 전체. 하루가 끝나면 항상 시연 가능한 상태로 커밋.
2. **API보다 폴백 먼저** — 모든 외부 API는 샘플 스냅숏(JSON)으로 먼저 개발하고, 키가 나오면 스위치만 켠다. 키 발급이 늦어져도 일정이 안 밀린다.
3. **컷 순서를 미리 정한다** — 밀리면 ① 환율 위젯 → ② iOS 스캔 → ③ 마진 차트 순으로 뺀다. **절대 사수: 데모 시나리오 3종 + 출처 표기 + 폴백 모드.**
